# Создание ролика «Роском Онлайн»

Рабочая директория: `roskom-video-studio/` (все команды выполнять из неё). Правила проекта — `roskom-video-studio/CLAUDE.md` (прочитай, если ещё не читал).

## 0. Окружение (один раз за сессию)
`npm run doctor`. Если нет RHVoice — `sudo apt-get install -y rhvoice rhvoice-russian`; нет Chromium — `npm install && npx playwright install chromium`.

## 1. План
Из запроса определи: тему, тип (`npm run types`; агент **content-planner**, если тем несколько или тема размыта), длительность (short 30–60 / medium до 90 / long до 180), формат (vertical по умолчанию), режим (auto по умолчанию; approval — если пользователь просит сначала показать сценарий).

`npm run new -- "<тема>" --type <type> --duration <short|medium|long>` → путь проекта.

## 2. Исследование и сценарий
1. Агент **researcher**: факты с официальными источниками → `research.md`.
2. Агент **scriptwriter**: `script.md` (Крючок → Проблема → Объяснение → Решение → CTA).
3. Агент **legal-reviewer**: проверка каждого утверждения, блок `legal` в storyboard.json, `sources.md`. Неподтверждённое — убрать из сценария.

## 3. Раскадровка
Агент **storyboard-director** заполняет `storyboard.json` (формат — CLAUDE.md). Затем агент **video-director** — разнообразие и динамика. `npm run validate -- <проект>` до отсутствия ошибок.

В режиме approval: покажи пользователю script.md и список сцен, дождись утверждения.

## 4. Сборка
`npm run build -- <проект>` (долгая команда: ~1–2 мин рендера на 10 с видео; запускай в фоне и жди уведомления). Конвейер сам: озвучка → тайминги → субтитры → музыка/SFX → рендер сцен → склейка → QA → обложка → publication.md.

## 5. Контроль качества
Агент **quality-reviewer** или сам: прочитай `quality-report.json`, сделай `npm run still -- <проект>` и посмотри кадры. Исправь storyboard.json и пересобери нужные сцены: `npm run build -- <проект> --scenes 2,4`.

## 6. Ответ пользователю
- путь к final.mp4 (или причина отсутствия: ошибка QA / ожидание юридического согласования — `npm run approve -- <проект> --by "ФИО"`);
- длительность, тип, голос;
- спорные утверждения, исключённые legal-reviewer;
- что лежит в publication.md (заголовки/тексты), обложка cover.png.
Отправь пользователю final.mp4 (или preview.mp4) и cover.png. Не публикуй ролик без отдельного разрешения.

## Правки существующего ролика
«последний ролик» = `npm run list` → самый свежий проект. Правишь storyboard.json → `npm run build` (кеш: пересобираются только изменённые сцены; при смене озвучки сдвигаются тайминги последующих сцен — они тоже пересоберутся автоматически).
