# Motion-слоты

Анимация из редизайна заказчика подключена на CSS (без библиотек) и включается атрибутом `data-anim="on"` на `<html>` (`ui.motion` в `src/content/site.ts`). При `prefers-reduced-motion: reduce` все анимации и переходы отключаются.

| Слот | Что сейчас анимировано |
|---|---|
| `hero-title` | Подъём строк H1 при загрузке |
| `hero-art` | Шкала 320–1440 px в первой карточке «что проверяем» |
| `process-line` | Прорисовка линии этапов при прокрутке (`animation-timeline: view()`, где поддерживается) |
| `case-reveal` | Однократное сжатие макета до телефонной ширины при появлении на экране |
| диалоги | Короткое появление (`pop`, 0,22 с) |

Остальные слоты (`section-intro`, `detail-focus`, `cta-accent`) свободны для авторской анимации.

## Слоты

| `data-motion`   | `data-motion-id`                         | Элемент                              | Будущая задача              |
|-----------------|-------------------------------------------|--------------------------------------|-----------------------------|
| `hero-title`    | `hero-title`                              | H1 первого экрана (строки — `[data-motion-layer]`) | Раскрытие по строкам |
| `hero-art`      | `hero-art`                                | Шкала 320–1440 px на первом экране   | Проход шкалы               |
| `section-intro` | `section-intro-<якорь>`                   | Заголовки смысловых блоков           | Появление при скролле       |
| `case-reveal`   | `case-01` … `case-03`                     | Превью работ                         | Маскированное раскрытие     |
| `process-line`  | `process-line`                            | Линия этапов                         | Прорисовка линии            |
| `detail-focus`  | `detail-case-01-form`, `detail-case-02-cards`, `detail-case-03-filters` | Детали интерфейсов в превью | Акцент / zoom |
| `cta-accent`    | `cta-accent`                              | Фон промежуточного CTA               | Движение графической формы  |

Проверить уникальность ID: `npm run test:e2e` (тест AC-18).

## Контракт

- Внешний элемент со `data-motion` фиксирует геометрию и размеры — его не анимируем.
- Анимируется вложенный `[data-motion-layer]` (transform / opacity / mask).
- Не анимировать контейнеры форм, sticky-шапку, элементы с клавиатурным фокусом и модальные окна.
- Не скрывать контент начальным `opacity: 0`. Исключение из редизайна — подъём строк H1: строки уезжают вниз внутри маски на 0,9 с и только при включённой анимации.
- Поддержать `prefers-reduced-motion` — `initMotion` в этом случае ничего не запускает.
- Не подключать GSAP / Motion / scroll-jacking «про запас» — только вместе с утверждённым storyboard.

## Подключение

```ts
"use client";
import { useEffect } from "react";
import { initMotion } from "@/animations";

useEffect(() => initMotion({
  "case-reveal": (el, layer) => { /* … */ return () => { /* очистка */ }; },
}), []);
```

Storyboard от дизайнера для каждого слота: объект, начальное/конечное состояние, триггер, длительность, easing, поведение на мобильном, fallback для reduced-motion.
