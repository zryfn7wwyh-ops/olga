# Отчёт о восстановлении vestnic.online (локальная копия)

Дата: 03.11.2026. Исходник: `vestniconline.zip` (73 файла, тема vestniconline).
Окружение проверки: Ubuntu 24.04, PHP 8.3.6, MariaDB 10.11, WordPress 7.1.4, Chromium (Playwright).

## 1. Что удалось воспроизвести точно

| Источник | Что есть | Чего нет |
|---|---|---|
| Архив темы | PHP-шаблоны, CSS (bootstrap, style, swiper, frontend.min.css от Elementor 3.7.1), JS (Vue 2.7.8, Swiper, Inputmask, app.js, квиз), `images/` | ядро WP, дамп БД, плагины, `wp-content/uploads` |
| `screenshot.png` | 1200×900, однотонный | как эталон главной не годится |
| Бэкап, сохранённый HTML, снимки прежней версии | **не переданы** | — |
| Публичный vestnic.online | **недоступен из среды сборки** (прокси возвращает 403; веб-архив не резолвится) | сравнение с текущей версией сайта не проводилось |

**Эталона нет, поэтому ни одна страница не сверена визуально с оригиналом.** Попиксельную сверку
(допуск 2 px, наложение) провести нельзя. Проверено соответствие исходникам темы:
разметка, каскад CSS, скрипты и сценарии. Все страницы ниже имеют статус «не проверена визуально».

## 3. Результаты проверки (scripts/check.cjs)

13 страниц × 5 ширин (1440, 1024, 768, 390, 360) = 65 проверок, плюс 10 сценариев. Сырые данные: `docs/screenshots/report.json`.

| Критерий | Результат |
|---|---|
| Горизонтальный скролл | нет ни на одной странице и ширине |
| Сырые шорткоды в тексте | нет |
| Ошибки PHP | журнал пуст |
| Ошибки JS (исключения) | нет (после исправления cookie-скрипта, см. §5) |
| Шрифты | Roboto 400 из Google Fonts; Font Awesome 5 Free 900 и Brands 400 загружены, иконки отрисовываются |
| Битые изображения | 38 на каждой странице — все из `/wp-content/uploads/` (см. §4) |
| Прочие сетевые ошибки | эмодзи WordPress с s.w.org (нет доступа к сети в среде проверки) |

## 5. Отличия от архива

| Файл | Изменение | Причина |
|---|---|---|
| `footer.php` | проверка `if (cookieButtonSecond)` перед `addEventListener` | кнопки `.btn_cookie-second` нет в разметке, на каждой странице была ошибка TypeError |

Всё остальное подключено извне темы (`wp-content/mu-plugins/vo-local-env.php`):

* jQuery подключается явно: `app.js` и Inputmask его требуют, а тема jQuery не подключает (на исходном сайте его подключали плагины);
* `[sc]`, область меню `max_mega_menu_1` и поля ACF работают только при отсутствии настоящих плагинов;
* только в локальной среде: приёмник заявок, перехват почты, отключение Метрики/Roistat/Mango, локальные uploads.

Наблюдения по исходникам без изменений: панель `.call_me_block` в закрытом состоянии выступает
у правого края на ~10 px (translate 400px при ширине 350 + отступе 60); `lead_name` в квизе — «Fedresurs.online».
