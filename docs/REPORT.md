# Отчёт о восстановлении vestnic.online (локальная копия)

Обновлено 05.11.2026. Исходники: `vestniconline.zip` (73 файла, тема vestniconline) и скриншоты
работающего vestnic.online, присланные владельцем 05.11.2026.
Среда проверки: Ubuntu 24.04, PHP 8.3.6, MariaDB 10.11, WordPress 7.1.4, Chromium (Playwright).

## 1. Источники и эталон

| Источник | Что есть | Чего нет |
|---|---|---|
| Архив темы | PHP-шаблоны, CSS (bootstrap, style, swiper, `frontend.min.css` из Elementor 3.7.1), JS (Vue 2.7.8, Swiper, Inputmask, app.js, квиз), `images/` | ядро WP, дамп БД, плагины, `wp-content/uploads` |
| `screenshot.png` | 1200×900, однотонный | как эталон не годится |
| **Скриншоты владельца, 05.11.2026** | главная от первого экрана до подвала; окна «Разместить объявление», «Рассчитать стоимость объявления», «Сформировать счёт», «Оплатить картой», «Оставить заявку оплаты по гарантийному письму», окно ликвидации; квиз (3 шага) | шапка над первым экраном, другие страницы, мобильная версия |
| Публичный vestnic.online | из среды сборки недоступен (прокси отвечает 403) | — |

Параметры эталона: Chrome в Windows, экран 1920×1080, масштаб системы 125%, то есть окно 1508 CSS px
при `devicePixelRatio` 1,25. Сравнение выполнено при тех же параметрах (`docs/compare/`).

## 2. Карта страниц

| URL | Шаблон | Источник контента | Статус |
|---|---|---|---|
| `/` (ID 10) | tpl-main.php «Главная» (вывод, см. ниже) | `content/home.html` + 5 сниппетов | **реконструирована по эталону** (без шапки над первым экраном) |
| все страницы на page.php | page.php | сниппеты `baner-header`, `messages_list`, `pochemuvigodno`, `formandprice`, `payments_method` | блоки реконструированы по эталону главной; собственный текст страниц — не хватает данных |
| `/kontakty/` (ID 1986) | page.php (не подтверждён) | — | **не хватает данных**: текст, адрес и шаблон |
| `/politika-konfidencialnosti/`, `/soglasie-pers-dannyh/`, `/soglasie-cookies/`, `/soglasie-rassylki/` | page.php (не подтверждён) | заголовки — из ссылок подвала | **не хватает данных**: текст документов |
| страницы ID 2019, 2028 | ? | footer.php: на них любая форма открывает окно ликвидации | **не хватает данных**: адрес, название, шаблон |
| записи, рубрики, поиск, 404 | single.php, archive.php, search.php, 404.php | тема | шаблоны восстановлены из исходников; записей нет |

**Почему главная собрана на tpl-main.php.** На эталоне блоки идут в том же порядке, что и вызовы `[sc]` в page.php,
затем идёт рамка `.contentBorderBlock` с текстом. Но page.php выводит над рамкой заголовок страницы
`h2.entry-title`, и CSS темы его не скрывает, а на эталоне заголовка нет. Поэтому содержимое главной
собрано в шаблоне «Главная»: сниппеты, затем рамка с текстом. Видимый результат одинаков в обоих вариантах;
точно ответит запись ID 10 из БД.

Служебные страницы для проверки шаблонов (`/test-…/`) — тестовые данные, не контент сайта; их состав описан в README.

| Критерий | Результат |
|---|---|
| Горизонтальный скролл, сырые шорткоды, ошибки PHP, исключения JS | нет |
| Шрифты | Roboto, Source Sans Pro, Font Awesome 5 загружаются |
| Битые изображения | только файлы из `/wp-content/uploads/` (см. §5) |
| «Перезвоните мне» → «Заказать звонок» | маска `+7(900)123-45-67`, валидация, отправка в локальный приёмник, закрытие |
| Мобильное меню, квиз (десктоп), виджет обратного звонка, tenModal через 30 с, cookie, все 18 окон app.js | работают |

## 6. Отличия от архива

| Файл | Изменение | Причина |
|---|---|---|
| `footer.php` | проверка `if (cookieButtonSecond)` | кнопки `.btn_cookie-second` нет в разметке, без проверки на каждой странице была ошибка JS |

Всё остальное подключено вне темы:
* `content/` — тексты главной, сниппеты и тела форм (импортируются `scripts/seed.php`);
* `wp-content/mu-plugins/vo-reconstruction*` — стили реконструированных блоков, таймер, Source Sans Pro;
* `wp-content/mu-plugins/vo-local-env.php` — совместимость с отсутствующими плагинами (Shortcoder, Max Mega Menu, ACF, jQuery) и изоляция локальной среды.
