# Подключение озвучки ElevenLabs

Код интеграции уже встроен в студию (`src/services/voice-generator.js`). Нужны только ключ и выбранный голос.

## 1. Аккаунт и тариф

1. Зарегистрируйтесь на elevenlabs.io.
2. Выберите **платный тариф** (Starter или выше). Бесплатный тариф не даёт права на коммерческое использование. Актуальные условия смотрите на странице тарифов.
3. Расход: 1 символ текста ≈ 1 кредит (модель `eleven_multilingual_v2`). У модели `eleven_flash_v2_5` расход примерно вдвое меньше. Ролик 40–60 с — это 600–900 символов. Повторная сборка без изменения текста кредиты не тратит: озвучка кешируется.

## 2. API-ключ

1. В кабинете ElevenLabs откройте **Developers → API Keys → Create API key**.
2. Права ключа: **Text to Speech** и **Voices: Read**. Остальное отключите.
3. По желанию задайте лимит кредитов на ключ, чтобы контролировать расход.
4. Скопируйте ключ. Ключ — это пароль: **не отправляйте его в чат и не коммитьте в репозиторий.**

## 3. Куда положить ключ

**Студия на вашем компьютере.** Создайте в `roskom-video-studio/` файл `.env` (образец — `.env.example`) и впишите:

```
ELEVENLABS_API_KEY=ваш_ключ
```

Файл `.env` в git не попадает.

**Студия в облачной сессии Claude Code.** Напишите Claude: «подключи ElevenLabs». Откроется защищённая форма: ключ сохранится в настройках среды и будет подставляться в запросы к `api.elevenlabs.io`. Claude его не увидит, в чат и репозиторий он не попадёт.

## 4. Выбор голоса

1. В ElevenLabs откройте **Voice Library**. Найдите голоса с русским языком (фильтр Language → Russian) и добавьте понравившиеся в **My Voices**. Можно и клонировать свой голос (Voice Cloning). Тогда у маскота будет уникальный голос.
2. Получите список голосов аккаунта и образцы с фразой маскота:

   ```bash
   npm run voices -- --provider elevenlabs
   ```

   - выводит `voice_id` всех голосов и делает до 8 образцов в `output/voice-samples/elevenlabs/`;
   - образцы конкретных голосов: `--ids id1,id2`; другое количество: `--limit 4`; свой текст — в кавычках в конце команды.

## 5. Включение

В `config/voice-settings.json`:

```json
"provider": "elevenlabs",
"elevenlabs": {
  "voiceId": "ВЫБРАННЫЙ_VOICE_ID",
  "modelId": "eleven_multilingual_v2",
  "stability": 0.5,
  "similarityBoost": 0.75,
  "style": 0,
  "speed": 1.0
}
```

- `speed`: 0.7–1.2 — темп речи.
- `stability`: выше — ровнее, ниже — эмоциональнее.
- Голос только для одного ролика: блок `"voiceSettings": {"provider": "elevenlabs", "elevenlabs": {"voiceId": "…"}}` в его `storyboard.json`.

Пересборка:

```bash
npm run build -- <проект>
```

Тайминги сцен, субтитры и анимация маскота подстроятся под новую озвучку автоматически.

## 6. Произношение

- Поле `say` в репликах раскадровки и словарь `pronunciation` в `config/voice-settings.json` работают и для ElevenLabs.
- ElevenLabs обычно сам правильно читает числа и даты. Если слово звучит неверно, добавьте его в словарь.

## Ошибки

| Сообщение | Причина |
|---|---|
| `HTTP 401` | неверный или отключённый ключ |
| `HTTP 402` | закончились кредиты или функция недоступна на тарифе |
| `HTTP 404` | неверный `voiceId` |
| `HTTP 429` | слишком много запросов — повторите позже |
| `Сеть: не удалось обратиться к api.elevenlabs.io` | хост закрыт сетевыми правилами среды или нет интернета |
