# Roskom Video Studio — видеостудия «Роском Онлайн»

Система автоматически делает короткие ролики с фирменным маскотом: сценарий → проверка законодательства → раскадровка → озвучка → анимация → субтитры → музыка → MP4 → обложка → тексты для публикации.

Вы пишете Claude Code одну фразу — **«Создай ролик на тему: …»** — и получаете готовое видео в `projects/<проект>/final.mp4`.

---

## 1. Установка (один раз)

Нужны: Linux или macOS, Node.js 20+, FFmpeg, RHVoice (бесплатный русский синтез речи), Chromium.

**Ubuntu / Debian:**

```bash
sudo apt-get install -y ffmpeg rhvoice rhvoice-russian
```

```bash
cd roskom-video-studio
```

```bash
npm install
```

```bash
npx playwright install chromium
```

Проверка окружения:

```bash
npm run doctor
```

Все пункты должны быть с ✓.

> **macOS:** `brew install ffmpeg`. RHVoice для macOS нужно собирать из исходников, поэтому проще подключить внешний синтез речи (раздел 5).

## 2. Создание ролика через Claude Code (основной способ)

Откройте Claude Code в корне репозитория и напишите, например:

- «Создай ролик на тему: Какие документы по персональным данным должны быть на сайте компании в 2026 году»
- «Сделай видео о регистрации в Роскомнадзоре на 45 секунд»
- «Сделай ролик в формате три ошибки про согласия на обработку данных»
- «Создай пять видео о персональных данных для владельцев бизнеса»

Claude по очереди запустит агентов: исследование, сценарий, юридическая проверка, раскадровка, режиссура. Потом соберёт видео, проверит качество и пришлёт результат.

Правки готового ролика:

- «Измени начало последнего ролика»
- «Поменяй голос маскота на женский»
- «Сделай видео более динамичным»
- «Убери коммерческую вставку»
- «Пересобери видео с новыми субтитрами»

При правке пересобираются только изменённые сцены.

**Режим с согласованием:** «Сначала покажи сценарий и раскадровку». Claude покажет текст и сцены, а видео соберёт после вашего «ок».

## 3. Ручные команды

| Команда | Что делает |
|---|---|
| `npm run doctor` | проверка окружения и маскота |
| `npm run types` | типы роликов |
| `npm run new -- "Тема" --type three-mistakes` | новый проект (каркас раскадровки) |
| `npm run validate -- <проект>` | проверка storyboard.json |
| `npm run build -- <проект>` | полная сборка ролика |
| `npm run build -- <проект> --scenes 2,3` | принудительно пересобрать сцены 2 и 3 |
| `npm run build -- p1 p2 p3` / `npm run build-all` | пакетная сборка |
| `npm run approve -- <проект> --by "ФИО"` | юридическое согласование и выпуск финала |
| `npm run still -- <проект>` | контрольные кадры по сценам (PNG) |
| `npm run voices` | образцы всех голосов → `output/voice-samples/` |
| `npm run list` | проекты и их статусы |

## 4. Что получается в папке ролика

```
projects/<проект>/
├── script.md            сценарий
├── storyboard.json      раскадровка (машиночитаемая, с фактическими таймкодами)
├── sources.md           юридические источники и дата проверки
├── voice.wav            озвучка
├── captions.srt         субтитры
├── preview.mp4          превью 540×960
├── final.mp4            финальный ролик 1080×1920, H.264, 30 fps
├── cover.png            обложка
├── publication.md       3 заголовка, описание, тексты для Telegram, VK Клипов, YouTube Shorts, хештеги, ссылка на услугу
└── quality-report.json  отчёт автоматической проверки
```

Если `final.mp4` нет, причина в `quality-report.json`:

- `status: "awaiting-approval"` — в ролике есть утверждения, которые должен согласовать специалист. Выполните `npm run approve`.
- `status: "failed"` — техническая ошибка, описанная в отчёте. Повреждённый файл система не выдаёт за готовое видео.

## 5. Настройки

- **Голос:** `config/voice-settings.json`.
  - `rhvoice.voice` — голос маскота. Мужские: aleksandr-hq, artemiy, mikhail, pavel, yuriy, vitaliy. Женские: elena, anna, irina, tatiana, victoria, arina. Сначала прослушайте образцы: `npm run voices`.
  - `rate` — скорость речи, `pauses` — паузы.
  - `pronunciation` — словарь произношения терминов.
- **Внешний синтез речи** (естественнее звучит, платный). Пошагово для ElevenLabs — [docs/elevenlabs.md](docs/elevenlabs.md). Кратко: скопируйте `.env.example` в `.env` и впишите ключ. Затем укажите `"provider": "elevenlabs"` или `"yandex"` в `config/voice-settings.json`. Нужные ключи:
  - ElevenLabs: `ELEVENLABS_API_KEY` и `elevenlabs.voiceId` (ID выбранного голоса);
  - Yandex SpeechKit: `YANDEX_SPEECHKIT_API_KEY`, при необходимости `YANDEX_FOLDER_ID`.
- **Бренд:** `config/brand.json` — цвета, шрифты, услуги, CTA.
  - ⚠ Палитра подобрана по цвету маскота: брендбук не передавался, а сайт был недоступен из среды сборки. Замените цвета на фирменные.
  - Логотип положите в `assets/logos/` (SVG или PNG). Он появится в плашке бренда и на финальной карточке.
- **Видео:** `config/video-settings.json` — режим (auto/approval), форматы 9:16, 16:9 и 1:1, диапазоны длительности, качество, громкость музыки.
- **Музыка:** по умолчанию играет собственная генеративная фоновая музыка без ограничений на коммерческое использование. Чтобы использовать свой трек:
  1. Положите файл в `assets/music/`.
  2. Создайте `assets/music/license.json`, например `{"track.mp3": {"license": "…", "commercial": true}}`.

  Треки без пометки `commercial: true` система не использует. Под речью музыка автоматически становится тише.
- **Звуковые эффекты:** по умолчанию синтезируются. Свои можно положить в `assets/sfx/` под именами whoosh.wav, pop.wav, ding.wav, alert.wav, tick.wav.

## 6. Маскот

Оригиналы лежат в `assets/mascot/original/`, описание поз — в `assets/mascot/poses.json`. Система:

- использует только эти изображения, без перерисовки и отражения;
- анимирует изображение целиком: появление, перемещение, покачивание, «говорящее» сжатие по громкости речи, смена поз, прыжок, наклон, стрелка-указатель;
- перед каждым экспортом проверяет SHA-256 файлов, чтобы маскот не был изменён.

Что нужно для следующего уровня анимации:

1. **Синхронизация рта с речью:** тело маскота без рта и 4–6 сменных форм рта в PNG с прозрачностью → `assets/mascot/layers/<поза>/`.
2. **Высокое разрешение для старых поз** (от 1400 px). Позы 2–20.png — около 470–640 px и на экране немного увеличены; новые позы уже 1400 px.

Новую позу добавляет одна команда (PNG с прозрачностью или JPG/PNG на белом фоне — фон вырезается автоматически, исходник сохраняется в `assets/mascot/source/`):

```bash
npm run import-mascot -- путь/к/файлу.jpg имя-позы --emotion "что выражает" --use "когда использовать"
```

Проверочное превью вырезки появится в `output/cutout-preview-<имя>.png` (на белом, тёмном и светлом фоне). Или просто пришлите картинки Claude: «добавь в базу ещё маскотов».

## 7. Почему свой движок, а не Remotion

По ТЗ нужно было проверить лицензию Remotion. Для компаний больше 3 человек Remotion требует платную Company License. Поэтому здесь свой движок по той же схеме:

- кадр — это HTML/CSS-композиция, отрисованная в Chromium по номеру кадра;
- кодирование выполняет FFmpeg (H.264).

Результат воспроизводим, редактируется через `storyboard.json` и не зависит от платных лицензий. Весь стек бесплатный: Node.js, Playwright/Chromium, FFmpeg, RHVoice, шрифт Inter (OFL).
