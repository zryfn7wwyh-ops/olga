Робот-герой, который дышит, пока никто не кликает.

Анимация на чистом CSS и SVG: плавное покачивание, взгляд по сторонам, моргание оптики, пульс ядра в груди. Без видео и canvas — около 6 КБ разметки. Вставляется в любой hero-блок сайта.

Как встроить

Скопируйте блок <section class="robot-hero"> целиком вместе со стилями из <style> выше — всё инлайновое, без сборки и внешних скриптов, поэтому вставляется в любую страницу. Чтобы перекрасить, поменяйте CSS-переменные в начале файла (--accent-cyan, --accent-amber и т.д.).

<!-- robot-animation/index.html -->
<section class="robot-hero">
  ... svg + разметка, без зависимостей ...
</section>
