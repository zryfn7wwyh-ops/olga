# Лендинг «Регистрация в Роскомнадзоре»

Статическая страница: HTML, CSS и JS без сборки. Шрифты подключены локально из `fonts/`.

## Запуск

```bash
cd site && python3 -m http.server 8080
```

Затем откройте http://localhost:8080/. Подойдёт любой статический сервер, например `npx serve site`.

## Как делалась вёрстка

Figma (`FJl1f2K8AlI9BTdbFuuwV5`, узел 1:20) и сайт roskom.online были недоступны из среды разработки: сетевая политика блокирует хосты, коннектор Figma не подключён.
Поэтому страница свёрстана по PNG-эталону (530×2000, уменьшенная копия десктопа).

* Ширина фрейма принята равной **1440 px**: при ней основная колонка эталона (x≈41–488) даёт контейнер 1216 px. Масштаб эталона ×2.717.
* Шрифты в макете неизвестны, по виду это Gilroy. Используются свободные **Manrope** (основной) и **Montserrat** (заголовки капсом). Если шрифт подтвердится, замените `--ff`/`--ff-caps` в `styles.css`.
* Сверка: 28 ключевых границ на 1440 px, все в пределах ±2 px (`docs/compare/measurements.txt`). Высота страницы 5435 против 5434 px у эталона.
* **После сверки шрифт увеличен по просьбе заказчика.** В эталоне мелкий текст 8–12 px, теперь основной текст 15–18 px, мелкий от 12 px. Блоки получают высоту по содержимому, поэтому страница стала длиннее эталона (5759 против 5434 px на 1440). Снимки в `docs/compare/` относятся к версии 1:1 до увеличения.

## Требует сверки (`data-verify` в HTML)

* Подписи к пяти иконкам под кнопками первого экрана: на скриншоте подписан только «Разработка документов под ключ».
* Варианты в списке «Внесение изменений в реестр Роскомнадзора» (сейчас «Да» / «Нет, первичная регистрация»).
* Порядок логотипов клиентов между 3-й и 4-й строками сетки (скриншоты не перекрываются).
* E-mail, правообладатель, годы и реквизиты в подвале.

## Адаптив

* ≥1680 px: в шапке полный блок партнёра Клерка; уже — только логотип.
* 1280–1439 px: меню и заголовки чуть мельче; рейтинг и блок Клерка скрываются ниже 1280.
* ≤1180 px: меню прячется под бургер.
* ≤1023 px: первый экран и блок экспертов в одну колонку, сетки 2 колонки.
* ≤640 px: всё в одну колонку, кнопки на всю ширину.

Горизонтальной прокрутки нет на 320, 360, 390, 412, 750, 768, 1024, 1100, 1280, 1440 и 1920 px.

## Изменения по просьбе заказчика

* Блоки «Логотипы клиентов» и «Отзывы» убраны со страницы.
* Логотип сайта заменён на присланный `assets/logo.svg` (шапка и подвал).
* Кнопки «Зарегистрироваться сейчас», консультации, «Узнать стоимость» и «Проверить» открывают окно «Оставить заявку».
* Верхнее меню и меню подвала — быстрые ссылки на блоки страницы; пункт текущего блока подсвечивается при прокрутке.
* Мобильная версия проверена на 320, 360, 390 (iPhone 13), 412 (Pixel 7), 750 (iPhone landscape), 768 и 1100 px: нет горизонтальной прокрутки, текст не мельче 12 px, зоны нажатия от 44 px; в окне заявки на телефоне форма идёт первой.
* Страница перестроена по скриншотам заказчика: новая шапка (Клерк, телефон 8 (800) 301-76-89, «Запрос КП»), первый экран с белой формой и списком услуг, единый синий блок экспертов с формой «Проверить бесплатно», схема «Вы должны быть зарегистрированы», новый баннер проверки, блоки «Преимущества», «Ответственность», «Наши клиенты», «Ответы на популярные вопросы» и плавающая плашка «Подобрать пакет документов». Контейнер расширен до 1320 px.
* Карточки «Типичных ошибок» подсвечиваются при наведении (как на скриншоте), постоянная подсветка второй карточки убрана.
