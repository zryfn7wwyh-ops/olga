# Сайт образовательного направления ООО «Кейс Групп»

Один лендинг по одному адресу `/`: блоки идут подряд, навигация — якорное меню. Отдельных страниц, маршрутов, форм, оплаты и рекламных элементов нет. Сведения, которые ещё не предоставлены, выводятся заглушками в квадратных скобках.

## Запуск

```bash
cd site
npm install
npm run dev     # http://localhost:5173
npm run build   # статические файлы в dist/ (+ public/sitemap.xml и public/robots.txt)
```

Стек: React 18, Tailwind CSS 3, Lucide React, Vite. `dist/` размещается на любом хостинге. Сборка открывается и с диска: `keys-group-preview.html` — тот же сайт в одном файле.

## Блоки и якоря

**Образовательная программа:** 1 `#program` · 2 `#audience` · 3 `#results` · 4 `#teachers` · 5 `#price` · 6 `#conditions`

**Сведения об образовательной организации:** 7 `#education` · 8 `#standards` · 9 `#managers` · 10 `#management` · 11 `#objects` · 12 `#grants` · 13 `#vacant` · 14 `#catering` · 15 `#budget` · 16 `#inter` · 17 `#documents` · 18 `#contract` · 19 `#founders`

Меню: на компьютере — закреплённое оглавление слева, на телефоне — кнопка меню в шапке; пункты сгруппированы, текущий блок подсвечивается. Прямая ссылка `https://<домен>/#price` открывает нужный блок.

## Как наполнить (компоненты не меняются)

Все данные — в `src/data/landing.js`:

- содержимое каждого блока — массив `parts` (абзацы, списки, таблицы, документы, уведомления, карточки преподавателей); типы описаны в начале файла;
- новый блок — добавьте объект в `blocks`, меню и нумерация обновятся сами;
- название платформы обучения задаётся один раз: `platform` в `src/data/placeholders.js`;
- **документы (блоки 8 и 9):** положите PDF в `public/docs/` и укажите у документа
  `file: 'docs/ustav.pdf'`, `format: 'PDF'`, `size: '1,2 МБ'`, `date: '01.11.2026'`.
  Появится ссылка «Скачать (PDF, 1,2 МБ)», файл откроется в новой вкладке. Пока `file: null`, показывается «Документ будет добавлен» / «Образец договора будет добавлен» — фиктивных скачиваний нет.

Плашка о стадии наполнения в шапке задаётся в `src/data/site.js` (`prototypeNotice`) — уберите её после наполнения.

## Индексация

До запуска закрыта (`.env`: `VITE_ROBOTS=noindex, nofollow`; `robots.txt` запрещает обход). Для публикации: `VITE_ROBOTS=index, follow` и сборка с `SITE_INDEXABLE=1 SITE_URL=https://<домен>`.
