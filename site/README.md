# Сайт образовательного направления ООО «Кейс Групп»

Один лендинг по одному адресу `/`: блоки идут подряд, навигация — якорное меню. Отдельных страниц, маршрутов, форм, оплаты и рекламных элементов нет. Выводятся только предоставленные сведения: поля без данных на сайт не попадают.

## Запуск

```bash
cd site
npm install
npm run dev     # http://localhost:5173
npm run build   # статические файлы в dist/ (+ public/sitemap.xml и public/robots.txt)
```

Стек: React 18, Tailwind CSS 3, Lucide React, Vite. `dist/` размещается на любом хостинге. Сборка открывается и с диска: `keys-group-preview.html` — тот же сайт в одном файле.

## Блоки и якоря

**Образовательная программа:** 1 `#program` · 2 `#audience` · 3 `#results` · 4 `#price` · 5 `#conditions`

**Сведения об образовательной организации** (порядок подразделов — по приказу Рособрнадзора № 1493): 6 `#common` · 7 `#struct` · 8 `#documents` · 9 `#education` · 10 `#managers` · 11 `#teachers` · 12 `#objects` · 13 `#paid` · 14 `#budget` · 15 `#vacant` · 16 `#grants` · 17 `#inter` · 18 `#catering` · 19 `#standards`

Меню: на компьютере — закреплённое оглавление слева, на телефоне — кнопка меню в шапке; пункты сгруппированы, текущий блок подсвечивается. Прямая ссылка `https://<домен>/#price` открывает нужный блок.

## Как наполнить (компоненты не меняются)

Все данные — в `src/data/landing.js`:

- содержимое каждого блока — массив `parts` (абзацы, списки, таблицы, документы, уведомления, карточки преподавателей); типы описаны в начале файла;
- новый блок — добавьте объект в `blocks`, меню и нумерация обновятся сами;
- поле без данных — просто не добавляйте его: на сайте не будет пустых строк и заглушек;
- **документы (блоки 8 и 9):** положите PDF в `public/docs/` и укажите у документа
  `file: 'docs/ustav.pdf'`, `fileName: 'ustav.pdf'` (латиницей), `format: 'PDF'`, `size: '1,2 МБ'`, `date: '01.11.2026'`.
  Появится ссылка «Скачать (PDF, 1,2 МБ)», файл откроется в новой вкладке. Пока `file: null`, показывается «Документ будет добавлен» / «Образец договора будет добавлен» — фиктивных скачиваний нет.

Плашка над шапкой задаётся в `src/data/site.js` (`prototypeNotice`); сейчас выключена (`null`).

## Размещение и индексация

Готовый к загрузке архив — `keys-group-site.zip` (внутри `ИНСТРУКЦИЯ.txt`). Сборка использует относительные пути и работает как в корне домена, так и в папке существующего сайта.

Индексация открыта (`.env`: `VITE_ROBOTS=index, follow`). Чтобы получить `sitemap.xml`, соберите с адресом сайта: `SITE_URL=https://<домен> npm run build`. Закрыть индексацию: `VITE_ROBOTS=noindex, nofollow` и `SITE_INDEXABLE=0`.

## Соответствие требованиям

Этот сокращённый прототип отражает выбранные заказчиком блоки и не подтверждает полного соответствия требованиям Министерства образования и науки. До публикации и отправки ссылки нужно отдельно проверить применимость остальных сведений, предусмотренных законом (ст. 29 273-ФЗ, приказ Рособрнадзора № 1493), и наполнить лендинг достоверными данными.

## Публикация документов

Документы лежат в `public/docs/` и подключаются в блоке `documents` файла `src/data/landing.js` (помощник `pdf(название, файл, размер_КБ, подпись)`).

Перед добавлением нового PDF:
- убедитесь, что закрашенные сведения действительно удалены: чёрный прямоугольник в Word или онлайн-редакторе текст не удаляет, его можно скопировать;
- уберите из файла метаданные автора. Документы на сайте пересобраны без них: из исходных файлов скопированы только страницы.
