# Лендинг «Регистрация в Роскомнадзоре»

Статическая страница: HTML, CSS и JS без сборки. Шрифты подключены локально из `fonts/`.

## Запуск

```bash
cd site && python3 -m http.server 8080
```

Затем откройте http://localhost:8080/. Подойдёт любой статический сервер, например `npx serve site`.

## Как делалась вёрстка

Figma (`FJl1f2K8AlI9BTdbFuuwV5`, узел 1:20) и сайт roskom.online были недоступны из среды разработки: сетевая политика блокирует хосты, коннектор Figma не подключён.
Поэтому страница свёрстана по PNG-эталону (530×2000, уменьшенная копия десктопа).

* Ширина фрейма принята равной **1440 px**: при ней основная колонка эталона (x≈41–488) даёт контейнер 1216 px. Масштаб эталона ×2.717.
* Шрифты в макете неизвестны, по виду это Gilroy. Используются свободные **Manrope** (основной) и **Montserrat** (заголовки капсом). Если шрифт подтвердится, замените `--ff`/`--ff-caps` в `styles.css`.
* Сверка: 28 ключевых границ на 1440 px, все в пределах ±2 px (`docs/compare/measurements.txt`). Высота страницы 5435 против 5434 px у эталона.

## Ассеты: что положить из макета

Картинки подключаются только если файл перечислен в `assets/manifest.json`. Положите файл и добавьте его путь в массив, HTML править не нужно.

| Файл | Где используется |
|---|---|
| `assets/experts.webp` | фото экспертов, карточка 546×432 |
| `assets/document-pen.webp` | иллюстрация документа с ручкой в баннере «Проверить», 372×263 |
| `assets/ban.webp` | знак запрета в блоке «Реальный пример отказа» (сейчас временная CSS-замена) |
| `assets/logos/*.svg` | 9 логотипов клиентов (сейчас вместо них названия текстом) |
| `assets/docs/otkaz-rkn.pdf` | документ отказа РКН для кнопки скачивания |
| фон с кольцами | первый экран: сейчас CSS-приближение в `.hero-bg` |

Пример `manifest.json`: `["experts.webp","document-pen.webp","ban.webp","logos/lada.svg","docs/otkaz-rkn.pdf"]`

## Цели действий, которые нужно задать

| Действие | Сейчас |
|---|---|
| Форма «Сформировать Уведомление» | нужен URL приёма в `data-endpoint`. Пока данные не уходят, пользователь видит сообщение, что отправка не подключена |
| Форма «Получить перечень документов» | то же |
| «Войти» | `#`, нужен URL кабинета |
| «Бесплатная Консультация» (шапка, подвал) | временно ведёт к форме экспертов |
| «Узнать стоимость» | временно ведёт к форме экспертов |
| «Проверить» | временно ведёт к форме уведомления |
| «Зарегистрироваться сейчас» | к форме уведомления |
| Политика конфиденциальности, документы в подвале, соцсети, пункты меню «Услуги», «Полезные материалы», «Штрафы» | `#` |

Сообщение об успехе показывается только после ответа сервера 2xx. Форма отправляет `multipart/form-data` методом POST.

## Требует сверки с исходником (`data-verify` в HTML)

* Телефон, график работы, e-mail, правообладатель и годы в подвале.
* Строка реквизитов в подвале: в эталоне нечитаема, сейчас стоит заглушка.
* Подпись под рейтингом 5.0.
* Имена авторов 2-го и 3-го отзывов. В эталоне 4 точки слайдера, но видны только 3 отзыва: остальные тексты нужны из макета.
* Варианты в выпадающих списках (ОПФ, мессенджер, услуга, вид деятельности) в эталоне не видны, сейчас стоят типовые.
* В первом экране видно 6 пунктов с галочками, а в ТЗ указано 7.

## Адаптив

* ≥1280 px: десктопная раскладка 1:1.
* 1024–1279 px: колонки сужаются, часть декора скрыта.
* ≤1023 px: меню прячется под бургер, первый экран и блок экспертов в одну колонку, сетки 2 колонки, отзывы по 2.
* ≤640 px: всё в одну колонку, кнопки на всю ширину, отзывы по одному.

Горизонтальной прокрутки нет на 360, 390, 768, 1024, 1280 и 1440 px.
