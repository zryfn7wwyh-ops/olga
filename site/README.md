# Информационный сайт об образовательной деятельности ООО «Кейс Групп» (прототип)

Сайт для публикации официальных сведений об образовательной деятельности и предоставления ссылки Министерству образования и науки Краснодарского края. Без продающих элементов: нет каталога, форм заявки, оплаты, отзывов, баннеров и рекламных CTA.

**Все значения — заглушки.** Наличие подраздела в прототипе не означает, что его содержание соответствует требованиям ст. 29 273-ФЗ и приказа Рособрнадзора № 1493. До публикации юридический отдел подтверждает статус ООО, применимость подразделов и состав обязательных сведений.

## Запуск

```bash
cd site
npm install
npm run dev            # http://localhost:5173
npm run build          # dist/ + генерация public/sitemap.xml и public/robots.txt
```

Стек: React 18, Tailwind CSS 3, Lucide React, Vite. Сборка в `dist/` — обычные статические файлы, размещаются на любом хостинге.

## Одна страница, постоянные якоря

Весь сайт — одна страница. Каждый подраздел имеет постоянную ссылку-якорь:

`#top` — начало · `#sveden` — сведения · `#common`, `#struct`, `#document`, `#education`, `#eduStandarts`, `#managers`, `#employees`, `#objects`, `#grants`, `#paid_edu` — 10 подразделов (подразделы «Финансово-хозяйственная деятельность», «Вакантные места», «Международное сотрудничество» и «Организация питания» убраны по решению заказчика) · `#contacts` · `#privacy`.

Пример прямой ссылки: `https://<домен>/#paid_edu`. Оглавление закреплено сбоку (на телефоне — раскрывающаяся панель под шапкой) и подсвечивает текущий подраздел.

**Важно для юристов:** в ТЗ предложены отдельные адреса `/sveden/...`. По решению заказчика сайт сделан одностраничным, подразделы открываются по якорям `/#common` и т. д. Нужно ли размещать подразделы именно по адресам `/sveden/<подраздел>`, надо сверить с действующей редакцией приказа № 1493 до отправки ссылки министерству.

## Как заполнять сведения (без изменения компонентов)

```
src/data/placeholders.js  заглушки (раздел 7 ТЗ)
src/data/site.js          шапка, футер, главная, политика ПД, плашка «Прототип»
src/data/programs.js      перечень реализуемых программ и модулей
src/data/sveden.js        все подразделы: slug, title, blocks
```

- Поле: `{ label, value, prop, confirm }` — замените `value`; `confirm: true` выводит метку «Требует подтверждения».
- Документ: `{ title, date, file, format }` — пока `file: null`, показывается «Документ будет загружен». Положите файл в `public/docs/` и укажите `file: '/docs/ustav.pdf'`, `format: 'PDF'`, `date`.
- Подраздел добавляется или исключается правкой массива `svedenSections` — оглавление и страница обновятся сами.
- Блок `review` содержит позиции справки ЮО (научная деятельность, результаты приёма, трудоустройство выпускников, план ФХД/смета, бюджетные и внебюджетные показатели — эти две позиции были в убранном подразделе ФХД) со значением «[Информация уточняется]» до заключения ЮО.
- Контакты в блоке `#contacts` берутся из «Основных сведений» — один источник данных.
- `prop` — предварительные идентификаторы для машиночитаемой разметки (выводятся как `data-prop`); перевести в `itemprop` после сверки с действующей редакцией приказа № 1493.

Компоненты: `Header`, `Sidebar` (оглавление), `InfoTable` (+ `FieldsTable`), `DocumentList`, `Footer`, `SvedenContent` (рендер блоков), `Accordion`.

## Перед направлением ссылки министерству

1. Удалить плашку «Прототип» (`prototypeNotice` в `site.js`).
2. Заполнить все обязательные поля достоверными данными, загрузить документы и выписку из реестра лицензий.
3. Открыть индексацию: `VITE_ROBOTS=index, follow` в `.env` и сборка с `SITE_INDEXABLE=1 SITE_URL=https://<домен>`.
4. Проверить доступность, разметку, форматы файлов и актуальность; провести юридическую и техническую приёмку.
