# Прототип образовательного сайта ООО «Кейс Групп»

Интерактивный адаптивный прототип по ТЗ. **Весь контент — заглушки.** Прототип не является подтверждением соответствия требованиям 273-ФЗ и приказа Рособрнадзора № 1493.

## Запуск

```bash
cd site
npm install
npm run dev            # разработка, http://localhost:5173
npm run build          # продакшн-сборка в dist/ (+ генерация public/sitemap.xml)
npm run preview        # просмотр собранной версии
npm run build:preview  # статическая сборка с HashRouter (dist-preview/) — открывается без настройки сервера
```

Стек: React 18, React Router 6, Tailwind CSS 3, Lucide React, Vite.

Для BrowserRouter сервер должен отдавать `index.html` на все пути (готово: `public/_redirects` для Netlify, `vercel.json` для Vercel; для nginx — `try_files $uri /index.html`).

## Маршруты

| Путь | Страница |
|---|---|
| `/` | Главная |
| `/education` | Каталог программ с фильтром по формату |
| `/education/:slug` | Страница программы (шаблон, 4 демо-программы) |
| `/sveden` | Сведения об образовательной организации — оглавление |
| `/sveden/common`, `struct`, `document`, `education`, `managers`, `employees`, `objects`, `paid_edu`, `budget`, `vacant`, `grants`, `inter`, `catering`, `eduStandarts` | 14 подразделов |
| `/contacts` | Контакты, место для карты, форма обратной связи |
| `/privacy`, `/consent`, `/cookies` | Правовые страницы-заглушки |
| `*` | 404 |

## Структура: контент отделён от компонентов (под CMS)

```
src/data/        контент и конфигурация
  placeholders.js  единые заглушки (раздел 10 ТЗ)
  site.js          реквизиты, меню, футер, правовые страницы, SEO
  home.js          блоки главной
  programs.js      программы и форматы обучения
  sveden.js        подразделы /sveden (блоки: fields, table, docs, persons, text, scheme, note)
  routes.js        список публичных URL для sitemap
src/components/  переиспользуемые компоненты (Header, Footer, Accordion, DataTable, DemoForm, Modal…)
src/pages/       страницы
scripts/generate-sitemap.mjs   sitemap.xml из routes.js (домен — переменная SITE_URL)
```

- **Подразделы /sveden** добавляются, меняются и исключаются правкой массива `svedenSections` — страница, меню и sitemap обновятся сами.
- **Документы:** у элемента `file: null` выводится статус «Документ будет добавлен» / «Файл не загружен». Укажите `file: '/docs/ustav.pdf'` и `updatedAt` — появится ссылка и дата.
- **Машиночитаемая разметка:** у полей есть предварительные идентификаторы `prop` (выводятся как `data-prop`). Перевести их в `itemprop` можно после сверки с актуальной редакцией требований.
- **Формы** работают в демо-режиме: валидация и сообщение об успехе без отправки на сервер.

## Доступность и SEO

- Версия для слабовидящих (кнопка с глазом в шапке): крупный шрифт, высокий контраст, без анимаций.
- Ссылка «Перейти к содержимому», видимый фокус, управление с клавиатуры (меню, аккордеоны, модальное окно с удержанием фокуса, Esc).
- Таблицы на мобильном выводятся карточками.
- Уникальные `title`/`description` на каждой странице, один H1, семантическая разметка.
- `robots.txt` закрывает индексацию, и `<meta name="robots" content="noindex">` стоит до публикации — уберите оба перед запуском.

## Перед публикацией

Нужно внести реальные сведения, лицензию, документы, программы и данные сотрудников. Юридический отдел должен подтвердить, что требования применимы именно к ООО «Кейс Групп», а технический специалист — что специальный раздел реализован корректно.
