# Сайт образовательного направления ООО «Кейс Групп» (прототип)

Один лендинг по одному адресу `/`: ровно 10 информационных блоков подряд с якорным меню. Отдельных страниц, маршрутов, форм, оплаты и рекламных элементов нет. **Все значения — заглушки в квадратных скобках.**

## Запуск

```bash
cd site
npm install
npm run dev     # http://localhost:5173
npm run build   # статические файлы в dist/ (+ public/sitemap.xml и public/robots.txt)
```

Стек: React 18, Tailwind CSS 3, Lucide React, Vite. `dist/` размещается на любом хостинге. Сборка открывается и с диска: `keys-group-preview.html` — тот же сайт в одном файле.

## Блоки и якоря

| № | Блок | Якорь |
|---|---|---|
| 1 | Название образовательной программы | `#program` |
| 2 | Целевая аудитория и задачи слушателей | `#audience` |
| 3 | Практические результаты освоения программы | `#results` |
| 4 | Педагогический состав | `#teachers` |
| 5 | Стоимость | `#price` |
| 6 | Условия обучения и документы по итогам | `#conditions` |
| 7 | Органы управления и структурные подразделения | `#management` |
| 8 | Документы образовательной организации | `#documents` |
| 9 | Образец договора об оказании образовательной услуги | `#contract` |
| 10 | Учредители | `#founders` |

Меню: на компьютере — закреплённое оглавление слева, на телефоне — кнопка меню в шапке. Текущий блок подсвечивается. Прямая ссылка `https://<домен>/#price` открывает нужный блок.

## Как наполнить (компоненты не меняются)

Все данные — в `src/data/landing.js`:

- тексты, списки, таблицы и поля — замените значения в квадратных скобках;
- преподаватели и органы управления — добавьте или уберите строки в `rows`;
- **документы (блоки 8 и 9):** положите PDF в `public/docs/` и укажите у документа
  `file: '/docs/ustav.pdf'`, `format: 'PDF'`, `size: '1,2 МБ'`, `date: '01.11.2026'`.
  Появится ссылка «Скачать (PDF, 1,2 МБ)», файл откроется в новой вкладке. Пока `file: null`, показывается «Документ будет добавлен» / «Образец договора будет добавлен» — фиктивных скачиваний нет.

Плашка о стадии наполнения в шапке задаётся в `src/data/site.js` (`prototypeNotice`) — уберите её после наполнения.

## Индексация

До запуска закрыта (`.env`: `VITE_ROBOTS=noindex, nofollow`; `robots.txt` запрещает обход). Для публикации: `VITE_ROBOTS=index, follow` и сборка с `SITE_INDEXABLE=1 SITE_URL=https://<домен>`.
