# Документы для публикации в Вестнике госрегистрации: комплект

## Базовый комплект — короткое напоминание

Для любого типа сообщения в Вестнике нужен базовый набор документов: бланк-заявка и сопроводительное письмо, которые формируются в личном кабинете, отдельное согласие на обработку персональных данных, копия решения органа управления компанией, документ о назначении руководителя или ликвидатора, доверенность представителя (если подаёт не руководитель) и платёжный документ. Этот набор одинаков для всех категорий сообщений — а вот что к нему добавляется дополнительно, зависит от конкретного типа. Разбираем по типам.

## Дополнительные документы для ликвидации

К базовому комплекту для ликвидации нужна копия листа записи или выписки ЕГРЮЛ, подтверждающая, что компания находится в процессе ликвидации. Без этого документа заявку технически не примут: журнал проверяет, что соответствующая запись уже внесена в реестр, прежде чем ставить сообщение в номер.

## Дополнительные документы для реорганизации

Для реорганизации к базовому комплекту добавляется выписка о начале реорганизации. Если в процедуре участвует несколько компаний, нужны решения каждого участника, а не только того юридического лица, которое подаёт заявку. Если среди участников есть акционерное общество, дополнительно нужны сведения о единоличном исполнительном органе каждого участника — без них текст сообщения для АО будет неполным.

## Дополнительные документы для уменьшения уставного капитала

Для уменьшения уставного капитала к базовому комплекту добавляется решение об уменьшении уставного капитала с указанием способа и условий уменьшения. Этот документ должен точно совпадать по реквизитам — виду, дате, номеру и органу, принявшему решение — с тем, что указано в тексте самого сообщения.

## Дополнительные документы для снижения чистых активов АО

Для этой категории специальных дополнительных документов сверх базового комплекта не требуется. Но важно помнить про принципиальное ограничение: снижение чистых активов публикуется в Вестнике только для акционерных обществ — для ООО аналогичные сведения в этом журнале не публикуются вовсе, они раскрываются только через Федресурс.

## Сводная таблица

| Тип сообщения | Дополнительный документ к базовому комплекту |
|---|---|
| Ликвидация | Копия листа записи или выписки ЕГРЮЛ о процессе ликвидации |
| Реорганизация | Выписка о начале реорганизации; решения всех участников; для АО — сведения о едином исполнительном органе каждого участника |

## Если нужна помощь со сбором комплекта

Собрать правильный комплект документов именно для своего типа сообщения, не упустив специфику конкретной процедуры, не всегда просто самостоятельно. Специалисты сервиса «Вестник Онлайн» — сервиса-посредника, который готовит и подаёт заявку через официальный личный кабинет журнала, а не сама редакция, — помогают собрать и проверить комплект перед подачей. Работа проходит дистанционно, без оформления собственной электронной подписи, с экономией до 30% на публикации.

## Частые вопросы

**Какой документ обязателен именно для ликвидации, помимо базового комплекта?**
Копия листа записи или выписки ЕГРЮЛ, подтверждающая, что компания находится в процессе ликвидации.

**Нужны ли решения всех участников при реорганизации, если их несколько?**
Да, нужны решения каждого участника, а не только того, кто подаёт заявку.

**Какой дополнительный документ нужен для уменьшения уставного капитала?**
Решение об уменьшении уставного капитала с указанием способа и условий уменьшения, с реквизитами, совпадающими с текстом сообщения.

**Нужны ли дополнительные документы для снижения чистых активов АО сверх базового комплекта?**
Нет, специальных дополнительных документов не требуется, но эта категория касается только акционерных обществ, а не ООО.

**Публикуются ли чистые активы ООО в Вестнике?**
Нет, для ООО эти сведения раскрываются только через Федресурс, а не через Вестник.
