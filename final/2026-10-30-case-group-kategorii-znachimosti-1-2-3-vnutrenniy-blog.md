# Категории значимости объектов КИИ — чем отличаются 1, 2 и 3

Три категории значимости объектов КИИ — не просто условная шкала «серьёзнее / менее серьёзно». Это разный конкретный объём требований к защите объекта: от минимального уровня доверия применяемых средств защиты до состава обязательных мер безопасности. Разбираемся, что именно меняется между категориями.

## Как определяется, какая именно категория присваивается

Категория объекта КИИ определяется по пяти группам критериев значимости — подробно мы разбирали их в статье блога про значимые объекты КИИ. Здесь важен другой момент: если по разным критериям получаются разные результаты, объекту присваивается наивысшая категория среди всех применимых показателей. Например, если по социальной значимости объект соответствует третьей категории, а по экономической значимости — второй, итоговой категорией будет вторая: наивысшая из полученных.

## Категория 1 — самая высокая

Первая категория присваивается, когда последствия возможной компьютерной атаки признаются наиболее серьёзными хотя бы по одному из пяти критериев значимости. Для объектов первой категории действует самый строгий минимальный уровень доверия применяемых средств защиты информации — не ниже 4-го (приказ ФСТЭК № 76). Также для таких объектов требуется максимально полный перечень мер защиты по приказу ФСТЭК № 239 — без исключений, которые могут быть обоснованы для объектов с менее высокой категорией.

## Категория 2 — промежуточная

Вторая категория присваивается при значимых, но не максимальных потенциальных последствиях. Минимальный уровень доверия СЗИ для таких объектов — не ниже 5-го. Перечень обязательных мер защиты шире базового набора, но не требует того объёма, который обязателен для объектов первой категории.

## Категория 3 — наименее строгая из значимых, но не «лёгкая»

Третья категория присваивается при наименее серьёзных из «значимых» последствий. Важно не путать это с объектом без категории: объект третьей категории всё равно признаётся значимым объектом КИИ со всеми базовыми обязанностями — разработкой модели угроз, подключением к ГосСОПКА, уведомлением об инцидентах в течение 24 часов. Подробно эти обязанности мы разбирали в статье про значимые объекты КИИ. Минимальный уровень доверия СЗИ для третьей категории — не ниже 6-го: самый мягкий из трёх уровней, но далеко не нулевой.

## Что практически меняется с ростом категории

С повышением категории расширяется и усложняется перечень обязательных мер защиты по приказу ФСТЭК № 239. Для старших категорий дополнительно требуются такие меры, как обнаружение вторжений, криптографическая защита каналов передачи данных, средства доверенной загрузки и мониторинг событий безопасности в режиме реального времени. Параллельно растут и требования к самим средствам защиты: минимальный уровень доверия становится строже — с 6-го для третьей категории до 4-го для первой.

При этом точный перечень мер для конкретного объекта определяется не одним лишь номером категории, а по результатам моделирования угроз — у двух объектов одной категории конкретный набор применяемых мер может отличаться в зависимости от специфики инфраструктуры.

## Можно ли заранее предположить категорию, не проходя процедуру

Точно предположить категорию «на глаз» нельзя. Пороговые значения показателей по каждому из пяти критериев установлены в приложении к Постановлению Правительства № 127 и требуют индивидуального расчёта для конкретного объекта с учётом его реальных характеристик. Подробный порядок этого расчёта — тема отдельной статьи блога о процедуре категорирования.

## Частые вопросы

**По какому принципу выбирается итоговая категория, если по разным критериям получаются разные результаты?**
Присваивается наивысшая категория среди всех применимых показателей — например, если по одному критерию получилась третья категория, а по другому вторая, итоговая категория — вторая.

**Чем отличаются требования к СЗИ для разных категорий?**
Минимальным уровнем доверия применяемых средств защиты информации — для первой категории не ниже 4-го уровня, для второй — не ниже 5-го, для третьей — не ниже 6-го.

**Нужна ли модель угроз для объекта третьей категории?**
Да, модель угроз и создание системы безопасности по приказам ФСТЭК № 235 и № 239 обязательны для всех значимых объектов КИИ, независимо от конкретной категории.

**Отличается ли перечень обязательных мер защиты между категориями?**
Да, объём и сложность мер по приказу ФСТЭК № 239 растут с повышением категории — для старших категорий требуются дополнительные меры, такие как обнаружение вторжений и средства доверенной загрузки.

**Можно ли заранее определить категорию объекта без прохождения процедуры категорирования?**
Точно нет — пороговые значения показателей установлены в приложении к Постановлению Правительства № 127 и требуют индивидуального расчёта для конкретного объекта.
