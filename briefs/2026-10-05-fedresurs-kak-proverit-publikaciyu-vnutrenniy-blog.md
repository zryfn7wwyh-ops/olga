2. Источник данных

Источник SERP:
WebSearch.

Ключевые факты:
- Проверка выполняется на сайте fedresurs.ru через поле «Поиск сведений о субъектах экономической деятельности» — по ИНН, ОГРН или наименованию компании.
- Если сведения о компании есть в базе, отображается список сообщений с датой публикации, типом сообщения и кратким содержанием; для полного текста нужно открыть конкретное сообщение.
- Статус сообщения проходит два этапа: сначала «Принято», затем — «Опубликовано». Это не одномоментный процесс — между подачей данных и финальным статусом может пройти время.
- Можно заказать официальную выписку из реестра по опубликованному сообщению — в бумажном или электронном виде, через личный кабинет. Выписка — удобное подтверждение для предоставления контрагенту, в суд или контролирующий орган.
- При публикации через специализированный сервис подтверждение (ссылка на сообщение, иногда выписка на e-mail) обычно предоставляется сервисом автоматически после публикации — отдельно искать и проверять вручную не требуется.

Проверена ли реальная выдача Яндекса:
Нет.

20. Факты, требующие проверки

- Поиск по ИНН/ОГРН/названию, статусы «Принято»/«Опубликовано» — подтверждено несколькими источниками, уверенность высокая.
- Выписка из реестра через личный кабинет — подтверждено.
- Конкретное время перехода из «Принято» в «Опубликовано» — не найдено точного универсального срока, в статье не утверждается категорично.
