13. Структура статьи

H2: Как определяется, какая именно категория присваивается
Раскрыть кратко (без повтора пяти критериев — отсылка на статью про значимые объекты): категория определяется по наивысшему значению среди всех применимых показателей пяти групп критериев значимости. Привести пример логики: если по социальной значимости объект соответствует 3-й категории, а по экономической — 2-й, присваивается 2-я категория (из материалов практики категорирования).
Формат: 1 абзац с примером.

H2: Категория 1 — самая высокая
Раскрыть: присваивается при наиболее серьёзных потенциальных последствиях хотя бы по одному из пяти критериев. Минимальный уровень доверия применяемых СЗИ — не ниже 4-го (приказ ФСТЭК № 76). Требует максимально полного перечня мер защиты по приказу ФСТЭК № 239 — без исключений, которые допустимы для менее высоких категорий.
Формат: 1 абзац.

H2: Категория 2 — промежуточная
Раскрыть: присваивается при значимых, но не максимальных последствиях. Минимальный уровень доверия СЗИ — не ниже 5-го. Перечень обязательных мер защиты уже базового набора, но не требует полного объёма, обязательного для 1-й категории.
Формат: 1 абзац.

H2: Категория 3 — наименее строгая из значимых, но не «лёгкая»
Раскрыть: присваивается при наименее серьёзных из «значимых» последствий — но объект всё равно признаётся значимым объектом КИИ, со всеми базовыми обязанностями (модель угроз, подключение к ГосСОПКА, уведомление об инцидентах в течение 24 часов — подробнее в статье про значимые объекты). Минимальный уровень доверия СЗИ — не ниже 6-го, самый мягкий из трёх, но не нулевой.
Формат: 1 абзац с отсылкой.

H2: Что практически меняется с ростом категории
Раскрыть: с повышением категории расширяется и усложняется перечень обязательных мер защиты по приказу ФСТЭК № 239 — для старших категорий дополнительно требуются такие меры, как обнаружение вторжений, криптографическая защита каналов, средства доверенной загрузки, мониторинг в режиме реального времени; при этом требуемый уровень доверия СЗИ становится строже (с 6-го до 4-го). Конкретный перечень мер для каждого объекта определяется индивидуально по результатам моделирования угроз, а не одним лишь номером категории.
Формат: 1 абзац, без точных числовых ориентиров по количеству подсистем.

H2: Можно ли заранее предположить категорию, не проходя процедуру

14. FAQ

Вопрос 1: По какому принципу выбирается итоговая категория, если по разным критериям получаются разные результаты?
Ответ: присваивается наивысшая категория среди всех применимых показателей — например, если по одному критерию получилась 3-я категория, а по другому 2-я, итоговая категория — 2-я.

Вопрос 2: Чем отличаются требования к СЗИ для разных категорий?
Ответ: минимальным уровнем доверия применяемых средств защиты информации — для 1-й категории не ниже 4-го уровня, для 2-й — не ниже 5-го, для 3-й — не ниже 6-го.

Вопрос 3: Нужна ли модель угроз для объекта 3-й категории?
Ответ: да, модель угроз и создание системы безопасности по приказам ФСТЭК № 235 и № 239 обязательны для всех значимых объектов КИИ, независимо от конкретной категории.

Вопрос 4: Отличается ли перечень обязательных мер защиты между категориями?
Ответ: да, объём и сложность мер по приказу ФСТЭК № 239 растут с повышением категории — для старших категорий требуются дополнительные меры, такие как обнаружение вторжений и средства доверенной загрузки.

Вопрос 5: Можно ли заранее определить категорию объекта без прохождения процедуры категорирования?
Ответ: точно нет — пороговые значения показателей установлены в приложении к Постановлению Правительства № 127 и требуют индивидуального расчёта для конкретного объекта.
